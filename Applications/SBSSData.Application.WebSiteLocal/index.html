SaddleBrook Senior Softball (SBSS) Data Viewer

Version 1.12.278 — Release Date Monday, October 6 2025
The SBSS Data Viewer lets you view accumulated statistics from games played. All this data is gathered from the public and official SaddleBrooke Senior Softball Association (SSSA) site.
The data from the current season are updated every weekday evening no later than 6:30 PM, after which you can see the all pages populated using the latest data. Data from other seasons can be viewed by selecting the season from the drop-down list when clicking the "Seasons" button. Welcome to the 2025 Fall season!
I'm sorry to say that this site will no longer be available after the Fall Season due to lack of interest especially from the SSSA board. It's been a fun project – a lot of time & work, and a labor of love. I hope you have enjoyed using it. I will continue to maintain the site and fix any bugs that are reported. For those who have expressed interest, I thank you for your support and encouragement. Have a great Fall season, and I hope to see you on the field.

Contents

The following table has links to the Data Viewer pages together with a short description. More contextual information is displayed on the page or if there is a link to a help/guide page. Each page has a link back to this home page.
Table of Contents
Links Description
About SBSS Data Viewer Tables The page is a detailed look at the features of Data Viewer tables using live tables that you view and test while reading the page. A must read if you haven't yet.
Game Results, Teams and Players This page contains all the data gathered from the SSSA site, which is stored in a file (called the Data Store) and is displayed using three perspectives.
  • For every played game not canceled or forfeited, the results for the teams and each of the players on the team are displayed. This is a lot of data!
  • Second, there is a table that views the results from the team perspective, so it shows the team standings and the player summaries for every game the team played.
  • Finally, the last perspective is from the player. All stats (including ranking) for every player in every team in the league is displayed. The data for all leagues (typically 8 or 9) are displayed.
Player Sheets Player Sheets focus directly on each player. Every player has their own "sheet" that has their summary stats for every league in which they played as well as rank, percentile and Z-score statistics.
Players Leagues Stats & Statistics Players Leagues Stats & Statistics has tables for leagues and player summary stats and statistics. For each league (and summary for Community and Competitive) there is table having all player stats for league. You can optionally view all league descriptive stats as well Z-scores for the computed stats for each player.
Definitions, Explanations & Details The page contains background information that is not in a specific data page providing a central location for the information This page contains a table document "Commonly Used Batting Stats Abbreviations" that defines the abbreviation used tables displaying player stats. For the sections "Percentiles and Ranking" and "Z-Scores and Statistics" describe why and how rankings, percentiles and Z-scores are used and calculated.
Data Store Information The data store is the file where the all the data from SSSA Web site are stored; technically it is JSON file. Useful to see how many games were played, which were recorded, canceled or forfeited, and how many teams and active players there are. This page displays a single table showing the data store information for the last few seasons including the current one.
Log Sessions TLDR; This is the contents of the log file for the current (or last completed) season. It contains details of the games that were played, marked as recorded, canceled or forfeited. It also shows the files that are deployed to the web site server.

Viewing Requirements

This Web site is best viewed in a desktop browser because of the size of the tables that can be nested and the number of tables. All pages render on a phone but can be hard to navigate and see everything. This has only been tested on chromium browsers (Chrome and Edge) and Android and iPhones. Your mileage may vary.
When you select a link to a page, if it is displayed in the same tab, to go back previous page just click on the link that is part of the page header.
